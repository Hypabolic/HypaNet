# slop/codex/lists/llm_constructions.txt
# Sentence and headline templates that LLMs reuse in UI and marketing copy, written as simple patterns.
# Patterns: L09-L19 (see CODEX.md for each id).
#
# Pattern syntax (deliberately small, so a rule can compile it to a regex over folded words):
#   - Literal words are matched after folding (lower case, apostrophes removed, punctuation dropped), so write
#     "it's" and "you're" naturally; they match "its" and "youre" in folded text.
#   - {x}, {y}, {z}  one to eight words (lazy). {w} exactly one word. {n} a number, with optional %, x, +, k, m or
#     a unit word after it.
#   - A line may hold one pattern only. Patterns match anywhere in a node unless they start with ^ (node start) or end
#     with $ (node end).
#   - Several sentences in one node ("Simple. Powerful. Yours.") are matched across sentence ends; the rule layer
#     keeps the sentence-end positions separately when a pattern needs them (the {w}. {w}. {w}. tricolon).
# Lines starting with # are comments.
#
# Provenance: patterns written for HypaNet from the constructions named in the sources on each section header
# (full citations in SOURCES.md). No pattern text is copied from a source file except where a source's
# own wording is the construction itself (e.g. "not just X, but also Y", which Wikipedia and stop-slop both name).
# Licence: MIT (the HypaNet repo licence).
