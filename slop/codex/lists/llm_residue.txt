# slop/codex/lists/llm_residue.txt
# Chatbot residue and template leftovers pasted into shipped UI: the assistant's own voice, prompt echoes, and
# placeholder identities or text that were never replaced. Patterns: L44 (chatbot residue), L45 (placeholder
# identities and template text).
#
# These are the highest-precision entries in the codex: "Certainly! Here's" or "Acme Inc" in a shipped string is
# almost never intended. They are not redundancy and belong to the rule layer. Exceptions the rule must allow: a
# product that is itself a chat assistant (its transcript strings may say "Sure!"), documentation and fixtures,
# example placeholders in a form field ("e.g. jane@example.com" is a legitimate format hint, LABELLING.md R8), and
# test or storybook files.
#
# Format: one phrase per line, lower case, natural spelling; fold before matching. Lines starting with # are comments.
# Provenance: Wikipedia "Signs of AI writing" §Collaborative communication (words to watch: "I hope this helps",
# "Of course!", "Certainly!", "You're absolutely right!", "Would you like...", "is there anything else", "let me
# know", "more detailed breakdown") and §Phrasal templates and placeholder text, CC BY-SA 4.0, cited; unslop-ui
# TELLS.md §8 "Placeholder identities left in" and "Great question!" (MIT); slop_scan.py "placeholder" rule
# (samigiman/anti-slop-skills, MIT); the rest added for HypaNet. The phrases are stock English or stock placeholders.
# Licence: MIT (the HypaNet repo licence).
