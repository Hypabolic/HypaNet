# slop/codex/lists/ui_consequence_markers.txt
# Words and phrases that signal a UI sentence adds new information: a consequence, scope, time, cost, condition,
# reason, audience or recovery path. Patterns: U09 (subtitle that adds), U13 (consequence body), U25 (useful
# helper), U35 (empty body with a cause), and the decision aid in CODEX.md §7.
#
# Use: these are KEEP evidence, the counterweight to the restating frames in ui_restating_frames.txt. A marker counts
# only when it is NOT already in the node the sentence would echo (the dialog title, heading or control label) and is
# not a synonym of that node's verb ("Discard this draft?" / "...will be deleted": "deleted" restates "discard", but
# "all 6 photos" in the same sentence is new scope). One marker that survives that check is enough to keep a sentence
# out of ECHO; NARRATE still needs the LABELLING.md §7 consequence test.
#
# Format: one entry per line, lower case, natural spelling (hyphens and apostrophes kept); fold an entry the way the
# rule layer folds node text (rules/README.md, "Normalised string") before matching. Inflected forms are listed
# explicitly (no stemmer). British and American spellings are both listed. Lines starting with # are comments.
#
# Caution from the prose linters: Vale's Google package flags every "will" (Google.Will, after
# developers.google.com/style/tense) and the weasels list (words/weasels, MIT) flags "all", "also", "only" and
# "enough". In UI copy those words usually carry the consequence or the scope, so do not import them as slop cues.
#
# Provenance: written for HypaNet from the guidance cited in CODEX.md §7 (Microsoft Win32 UX guide,
# Confirmations: "use the term permanently to indicate that an action can't be undone" and the loss categories
# "data loss or financial loss", "system access", "privacy"; Apple HIG Alerts: "describe what happened, the context in
# which it happened, and why"; Atlassian empty state: "Include the reason for the empty state and where they can go
# next"). Entries are common English words; selection and grouping are HypaNet's own. Licence: MIT (repo licence).
