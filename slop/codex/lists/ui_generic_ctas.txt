# slop/codex/lists/ui_generic_ctas.txt
# Action labels (buttons, links, menu items) that name a gesture or a stock phrase instead of the outcome.
# Patterns: U29 (vacuous action label), U30 (gesture lead), U31 (CTA repeated across sections).
#
# Use: rule layer only (LABELLING.md aside R7). A control is never the flagged side of an echo (LABELLING §5 rank 1),
# and these labels are not redundant copy; the network does not score them. The list is longer than
# rules/src/lists.js VACUOUS_LABELS on purpose: the blocks below say which entries are always vacuous and which only
# in context. Match the WHOLE folded label (rules/README.md, "Normalised string"), not a substring.
#
# Format: one entry per line (alphabetical within each block), lower case; lines starting with # are comments.
#
# Provenance: written for HypaNet. Grounding: Apple HIG Writing ('just saying "Send" often works better than "Let's do
# it!"'; 'avoid using "Click here"'); Apple HIG Alerts ('Avoid using OK as the default button title unless the alert
# is purely informational'); Mailchimp web elements ('Don't say things like "Click here!" or "Click for more
# information" or "Read this."'; "Button copy should always include verbs"); NN/g writing links ("avoid generic links
# such as Read more, or Click here"); Microsoft Win32 UX guide ("Prefer specific labels over generic ones");
# Atlassian empty state ("Use action verbs ... rather than vague terms like OK"); Shopify ("start with a strong verb
# that describes the action"). Licence: MIT (repo licence).
