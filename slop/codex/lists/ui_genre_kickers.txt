# slop/codex/lists/ui_genre_kickers.txt
# Section-genre words: eyebrows, kickers and overlines that name the KIND of section rather than its subject.
# Patterns: U01 (kicker restating the heading), U02 (genre kicker), U03 (decorative label strip).
#
# Use: LABELLING.md K1. An eyebrow whose whole text is one of these is not a category label: it is ECHO -> the
# heading when the heading contains the same word or its stem, or is itself a genre word of the same kind, and DECOR
# otherwise. A word that names the product's real subject (Camping, Security, Recipes) is K1 KEEP and is not here.
# Match the WHOLE folded eyebrow text (rules/README.md, "Normalised string"), optionally after stripping a leading
# index ("01", "02 /") or glyph.
#
# Block A is the list LABELLING.md K1 freezes with the guide. Block B holds close variants proposed by this codex
# under K1's "and their close variants" clause; they are candidates until LABELLING.md is revised, and the labeller,
# not this file, decides a disputed one. Block C holds message-genre titles, kept separate because they sit on
# dialogs and banners, not sections (see ui_status_genre_titles.txt for the full set).
#
# Format: one entry per line (alphabetical within each block), lower case, natural spelling; lines starting with # are comments.
#
# Provenance: Block A copied from slop/LABELLING.md §6 K1 (HypaNet). Block B written for HypaNet from common landing
# page section names; grounding: REI Cedar eyebrow guidance ("Do use eyebrows for categories or groupings", "Don't use
# eyebrows as headings"; [anti-slop-guides] B9), GOV.UK Service Manual ("Headings should describe the purpose
# of the text that follows"). Licence: MIT (repo licence).
