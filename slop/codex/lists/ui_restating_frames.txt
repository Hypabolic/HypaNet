# slop/codex/lists/ui_restating_frames.txt
# Frames that wrap a restatement: the words a dialog body, subtitle or helper uses when it says its title or label
# again. Patterns: U04 (subtitle echo), U05 (generic-verb subtitle), U10 (dialog body restating the title), U11
# (body explaining the buttons), U18 (status body restating its title), U23 (helper restating the label), U32 (control
# plus caption saying what it does).
#
# Use: strip these frames, then strip the words of the node the sentence would echo (and their synonyms). If nothing
# is left, the sentence restates (ECHO, or NARRATE when it explains a visible control). If something is left, look it
# up in ui_consequence_markers.txt and ui_instruction_markers.txt (CODEX.md §7). A frame on its own is never
# evidence of slop: "Are you sure you want to leave? Your 3 unsent messages will be lost." keeps its second sentence.
#
# Format: one entry per line, lower case, natural spelling; fold as the rule layer does (rules/README.md,
# "Normalised string"). Lines starting with # are comments.
#
# Provenance: written for HypaNet. Grounding: Microsoft Win32 UX guide, Confirmations ("Are you sure you want to
# [perform an action]?" as the routine-confirmation phrasing; "Don't repeat the main instruction with slightly
# different wording") and User interface text ("Don't have supplemental explanations that merely restate the label");
# Apple HIG Alerts ("Avoid explaining alert buttons"); Atlassian empty state ("Avoid repeating content from the
# title"). Licence: MIT (repo licence).
