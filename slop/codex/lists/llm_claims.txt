# slop/codex/lists/llm_claims.txt
# Unsupported claims LLMs write into product copy: speed and ease promises, invented precision, vague social proof,
# reassurance boilerplate and manufactured urgency. Patterns: L28 (speed and ease promises), L29 (invented
# numbers; see the regex notes, not a word list), L30 (vague social proof), L31 (reassurance boilerplate), L32 (false
# urgency).
#
# None of these is redundancy in the LABELLING.md sense; they are claims a linter cannot verify. The rule layer should
# report them as "check this claim" findings, never as errors, and only in promotional slots (hero, subtitle, feature
# card, stat, CTA band, testimonial). A number with a source, a date or a link beside it is not a finding.
#
# Format: one phrase per line, lower case, natural spelling; fold before matching. Section L29 holds patterns in the
# llm_constructions.txt syntax ({n} a number with optional %, x, +, k, m or unit word; {x} one to eight words).
# Lines starting with # are comments.
# Provenance: deslop-copy and slop_scan.py "fake-stats" (samigiman/anti-slop-skills, MIT), unslop-ui TELLS.md §5 and
# §8 "Fabricated social proof", "Fake urgency", "Newsletter ... No spam. Unsubscribe anytime." (MIT), tasteskill
# copy.md §5 (cited), Wikipedia "Marketing buzzspeak" essay ("award-winning", "cutting edge"; cited); the rest added
# for HypaNet. Licence: MIT (the HypaNet repo licence).
