# slop/codex/lists/ui_static_status_claims.txt
# Status words that appear in pills, badges and dot labels. Patterns: U42 (decorative status marker), U43 (bound
# status, KEEP), U44 (repeated device).
#
# Use: LABELLING.md §6 "Static status claims" and K2. A pill whose whole text is one of these is DECOR (R11) when its
# text and colour are fixed in the markup and it is not the only statement of a real, dated fact; it is KEEP (K2) when
# the text or colour is bound to data (`stateful`), differs between siblings, or is part of a legend. The list says
# which words to inspect; the binding decides. Match the whole folded pill text after dropping a leading dot, sparkle
# or emoji glyph (those glyphs are aside R11g when the words are KEEP).
#
# Format: one entry per line (alphabetical within each block), lower case; lines starting with # are comments.
#
# Provenance: written for HypaNet. Grounding: GOV.UK Design System, Tag ("Tags are only used to indicate a status";
# "The more you add, the harder it is for users to remember them"; [anti-slop-guides] B4); Hallmark gate 63
# ("decorative status dots before labels", legal for "a live state"); Microsoft Win32 UX guide (exclamation points
# acceptable to "call attention to Web content ('New!')", which is the one sanctioned use of "New"). Licence: MIT.
