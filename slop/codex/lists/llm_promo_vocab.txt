# slop/codex/lists/llm_promo_vocab.txt
# Promotional vocabulary that LLMs reach for when asked to write app, website or marketing copy.
# Patterns: L01 (hype verbs), L02 (inflating adjectives and adverbs), L03 (abstract nouns), L08 (AI-as-headline).
#
# Format: one entry per line, lower case, natural spelling (hyphens and apostrophes kept). Fold an entry the same way
# the rule layer folds node text (rules/README.md, "Normalised string") before matching. Inflected forms are listed
# explicitly because the rule layer has no stemmer. British and American spellings are both listed where copy uses
# both. Lines starting with # are comments.
#
# Signal strength: one hit is weak evidence; two or more distinct entries in one node, or the same entry on several
# nodes of one screen, is the useful signal (Wikipedia "Signs of AI writing" makes the same point for its word list).
# Many entries are ordinary English in the right place ("transform" in an image editor, "robust" in a statistics
# tool), so the rule layer should report density, not single words.
#
# Provenance: compiled for HypaNet from the catalogues cited per section (see SOURCES.md). The entries are
# common English words; the selection and grouping are HypaNet's own. Licence: MIT (the HypaNet repo licence).
# Sources that list these words: deslop-copy and slop_scan.py (samigiman/anti-slop-skills, MIT), unslop-ui TELLS.md §8
# (claudiusararu/unslop-ui-skill, MIT), stop-slop phrases.md (hardikpandya/stop-slop, MIT), Sathya "Avoid landing
# page words" (microcopyexamples.substack.com, cited only), Kobak et al. excess_words.csv (berenslab/llm-excess-vocab,
# MIT), Wikipedia MOS:PUFFERY and WP:AIPUFFERY (cited only; no list copied wholesale).
