**Design (summary).** The network is a hand-wired pipeline; every weight not mentioned is 0.

*Residual dims.* Token embedding sets flags: d0 const 1, d1 hashed word, d2 digit group, d3 `>`, d4 `NL@`, d5 `EOE`, d6 read_file/list_dir, d7 search, d8 edit/write/revert, d9 `in`, d10 `lines`, d12 any tool name, d14 `error`, d15 `FAILED`, d17 `pending`, d18 any status word. Offset embedding gives d19 = o, d20 = o², d21/22/23 = offset 7/10/14 flags. Hashed ids and digit groups get a residue code A (one-hot of id mod 4, 5, 7 → d32–47, 140 distinct codes) and hashed ids also code B (mod 3, 13 → d48–63).

*Layer 0 attention.* Heads 0/1 attend to the previous (resp. second-previous) token of the same event using the exact quadratic score −8(oᵢ−oⱼ−k)² built from (1, o, o²), copying "`>` before me", "`FAILED` before me" (d25, d26) and "`NL@` two back" (d27). Head 2 broadcasts the tool class (token at offset 7) to every token of the event (d28–30). Head 3 counts `NL@` lines with a BOS sink → d31 = k/(k+1).
*Layer 0 MLP.* Gated key codes: K_rev (code at h_old / h_new tokens, d64–95), T (code at read/list path, first search query word, or the passed-count digit after `FAILED`; d96–111); status_true (status word right after `>`, d112); FNC (`FAILED` with no counts, d113).
*Layer 1 attention.* Heads 0/1: an h_new token's raw code queries K_rev keys of the 7 previous events (full residue match beats the BOS sink, partial matches lose) → "this edit returns a file to an earlier state" (d116/117, both codes). Head 2: same for T → "same file re-read / same failing count again" (d118). Head 3 broadcasts error/pending status (d114/115); head 4 marks events with a `lines=` field (d24).
*Layer 1 MLP.* Role-gated reversion flag REVg (needs both code matches, hashed, after `>`), re-read flag REPg, same-count flag CNTg, NOOP (mutation with no hunk line, d127).
*Layer 2 attention.* Heads 0–3 gather each flag to the event's EOE (max-like). *MLP:* INEFF_e = clip(REV+CNT+NOOP+error+pending) + relu(REP − has_lines); fail_e = clip(error + 0.7·pending + CNT + FNC).
*Layer 3 attention.* Window sums at the EOE over the last 8 events (REV, INEFF → d32, d33), last 5 events (fail → d34) and last 16 events with a dominant BOS sink (fail count/(256+k) → d35). *MLP:* clipped ramps: osc (≥2 reversions), sc (≥5 ineffective), rf (a fail in the last 5), sh (≤4.5 weighted fails in the last 16). *Head:* OSC = 12·osc; STALLED = 8·sc + 8·INEFF_t − 3·rf − 3·sh − 9; RECOVERY = 6·rf + 6·sh − 6; PRODUCTIVE = 0.5.
