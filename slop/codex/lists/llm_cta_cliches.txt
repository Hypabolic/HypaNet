# slop/codex/lists/llm_cta_cliches.txt
# Stock call-to-action labels and CTA-band headlines that LLMs produce by default. Patterns: L26 (stock CTA
# labels), L27 (CTA-band question and closer headlines).
#
# The existing rule slop/vacuous-action (aside R7, rules/src/lists.js VACUOUS_LABELS) already flags a button or link
# whose whole label is one of a short set of vacuous labels (the guide's R7 examples and a few more). This list
# extends that set with the labels LLMs add around it; entries already in VACUOUS_LABELS are repeated here only so this
# file stands alone, and are marked "(R7)". Whole-label match: a button or link whose folded text equals an entry.
# Headline entries (section L27) match a heading or CTA-band body anywhere.
#
# Do not flag: a label that names its object ("Start free trial", "Book a demo" when a demo is the product's real
# next step, "Download for Mac"). Several entries below are fine when the surrounding screen makes the outcome
# concrete; the rule should treat them as R7 candidates, not as errors (rules/src/lists.js gives the same caveat for
# "Continue" and "Next", which are deliberately absent here too).
#
# Format: one phrase per line (alphabetical within each block), lower case, natural spelling; fold before matching. Lines starting with # are comments.
# Provenance: unslop-ui TELLS.md §5 and §8 "CTA clones" (MIT), Hallmark gates.md gate 19 "stock second action"
# (Nutlope/hallmark, MIT), tasteskill copy.md §4 and lint.mjs (via an earlier HypaNet survey), deslop-copy (MIT);
# the rest added for HypaNet. Licence: MIT (the HypaNet repo licence).
